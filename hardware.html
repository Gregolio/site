1.1 Componentes Internos

1.1.1 CPU

O processador é o componente principal responsável pelo processamento de instruções e execução de tarefas em um computador.

1.1.2 Armazenamento

Os dispositivos de armazenamento mantêm dados e informações, incluindo HDDs, SSDs e memórias flash.

1.1.3 Memória

A memória RAM armazena dados temporários para acesso rápido pelo sistema operacional e programas.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte energia elétrica para alimentar os componentes internos do computador.

1.2 Componentes Externos

1.2.1 Teclado

Dispositivo de entrada que permite ao usuário inserir dados no computador.

1.2.2 Monitor de Vídeo

Exibe informações visuais geradas pelo computador.

1.2.3 Mouse

Dispositivo apontador usado para navegar e interagir com a interface gráfica do sistema operacional.

1.2.4 Impressora

Permite a impressão de documentos e imagens em papel.

1.2.5 Plotter

Utilizado para impressões gráficas de grandes formatos, como mapas e projetos arquitetônicos.

1.2.6 Scanner

Converte documentos físicos em imagens digitais.

1.2.7 Gabinete

Envolve e protege os componentes internos do computador.

1.2.8 Web Cam

Permite a captura de imagens e vídeos para transmissão ao vivo.

1.2.9 Caixas de Som

Reproduzem áudio gerado pelo computador.

1.2.10 Microfone

Captura áudio para transmissão ou gravação.

1.2.11 Headset

Combina fones de ouvido e microfone para comunicação e áudio.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces Sem Fio

Permitem conexões sem a necessidade de cabos, como Bluetooth e Wi-Fi.

1.3.2 Áudio

Interfaces que permitem conexões de entrada e saída de áudio, como conectores P2.

1.3.3 Rede (Ethernet)

Conexões por cabo para redes locais.

1.3.4 VGA

Interface gráfica para conexão de monitores.

1.3.5 HDMI

Interface para transmissão de áudio e vídeo de alta definição.

1.3.6 USB

Interface versátil para conexão de dispositivos periféricos.

2. Grandezas Elétricas

2.1 Potência Elétrica

Representa a taxa de transferência de energia elétrica.

2.2 Tensão Elétrica

Indica a diferença de potencial elétrico entre dois pontos.

2.3 Corrente Elétrica

Fluxo de carga elétrica em um condutor.

3. Unidades de Medida Utilizadas na Informática

3.1 Capacidade de Armazenamento

3.1.1 bit

A menor unidade de informação digital.

3.1.2 Byte

Equivale a 8 bits e é uma unidade comum de armazenamento.

3.1.3 Múltiplos

Incluem Kilobyte (KB), Megabyte (MB), Gigabyte (GB), entre outros.

3.2 Frequência

3.2.1 Hertz

Unidade de medida que indica ciclos por segundo.

3.2.2 Múltiplos

Incluem Kilohertz (kHz), Megahertz (MHz), Gigahertz (GHz).

3.3 Largura de Banda

3.3.1 Capacidade do Canal

A quantidade máxima de dados que um canal pode transmitir.

3.3.2 bit/seg (bps)

Velocidade de transmissão medida em bits por segundo.

3.3.3 Múltiplos

Incluem Kilobits por segundo (Kbps), Megabits por segundo (Mbps).

3.4 Taxa de Transferência

3.4.1 Tráfego no Canal

Indica o volume de dados transmitidos em um período de tempo.

3.4.2 Byte/seg (Bps)

Medida de velocidade de transmissão em bytes por segundo.

3.4.3 Múltiplos

Incluem Kilobytes por segundo (KBps), Megabytes por segundo (MBps).
